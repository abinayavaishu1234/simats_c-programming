C PROGRAMMING – CO3 ASSIGNMENT 3
Reference package: S. Shwetha | Register No: 1911260046 | Course: CSA02

IMPORTANT
This ZIP contains sample C programs, sample test data, and outputs produced by compiling
and running the programs with GCC. It is for reference and practice only. It is not evidence
of your personal execution. The assignment specifies pair work; both students must execute
and understand every question individually in their own repositories.

TASKS
Q1: Binary search in a sorted library catalogue.
Q2: Bubble, selection and insertion sort comparison on sorted, nearly sorted,
    reverse-sorted and mixed arrays.
Q3: Merge two descending merit lists, including an empty-list test.
Q4: 2-D rainfall analysis using a small 3 x 4 example.
Q5: Word count and palindrome check without string.h.
Q6: Sort and search a small resident-name directory and detect duplicates.
Q7: Count valid/invalid election votes, rank candidates and detect a tie.

COMPILE AND RUN
gcc -std=c11 -Wall -Wextra filename.c -o program
./program
On Windows: program.exe

No keyboard input is required for these sample runs; the test data is included in each
source file. Each *_output.txt file contains the captured run output, and each
*_compile.txt file records the compiler command.

For the full assignment, add your own required measurements, larger test sets, analysis,
screenshots, individual contribution record, and GitHub repository links. Q2 and Q6 use
small demonstration data, not the full scale required by the assignment.
