CO4 ASSIGNMENT 4 - C PROGRAMS
================================

This ZIP follows the folder-per-task layout of the supplied CO1 assignment ZIP.

Compiler:
GCC (compile using -Wall -Wextra)

Compile and run a single-file task:
    gcc -Wall -Wextra Task01/task01.c -o task01
    ./task01

Repeat with the matching source path and executable name for Tasks 02, 03, 04 and 06.
Task 5 (main file with storage-class examples):
    gcc -Wall -Wextra Task05/task05.c -o task05
    ./task05

Task 5 (two-file extern example):
    gcc -Wall -Wextra Task05/main_extern.c Task05/counter.c -o extern_demo
    ./extern_demo

Folders:
    Task01 - patient register, nested structures and structure pointer
    Task02 - nested parcel structures, pointer access and selection sort
    Task03 - tagged union and memory-size demonstration
    Task04 - structure pointer and account interest
    Task05 - auto, static, extern and register storage classes
    Task06 - canteen inventory, tagged union, stock validation, expiry warning and revenue sorting

The completed assignment report is included as CO4_Assignment_4_Completed.docx.
